# SugarCRM

> SugarCRM (rebranding as Sugar AI) is a B2B sales CRM platform serving 4,000+ customers across 120+ countries. Its products span Sugar Sell (sales automation), Sugar Serve (customer service), Sugar Market (marketing automation), and sales-i (sales intelligence). The Sugar REST API is instance-hosted at https://<site_url>/rest/v{version}/ (v10 through v11_20), authenticated with two-legged OAuth 2.0.

## API
- [Sugar REST API Developer Guide](https://support.sugarcrm.com/documentation/sugar_developer/): REST endpoints, modules, filtering, and OAuth2 authentication (per-instance base URL /rest/v11_x/).

## Docs
- [Documentation Portal](https://support.sugarcrm.com/documentation/): Full Sugar administration and developer documentation.
- [Authentication](authentication/sugarcrm-authentication.yml): Two-legged OAuth 2.0 (password + refresh_token grants), OAuth-Token header.
- [Conventions](conventions/sugarcrm-conventions.yml): JSON, ISO 8601 dates, URI-path versioning, offset pagination (max_num/offset/next_offset), /{module}/filter querying.
- [Error Catalog](errors/sugarcrm-problem-types.yml): SugarApiException classes and HTTP status codes; {error, error_message} envelope.
- [Lifecycle](lifecycle/sugarcrm-lifecycle.yml): URI-path versioning v10-v11_20, status page, deprecation track.
- [Conformance](conformance/sugarcrm-conformance.yml): OAuth2/OIDC/SAML, ISO 27001:2022, SOC 2 Type II, CSA STAR, GDPR/CCPA.
